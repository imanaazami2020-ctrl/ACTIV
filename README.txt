ربات نمایش آیدی و مشخصات عمومی تلگرام

فایل‌ها:
- bot.py: کد اصلی ربات
- requirements.txt: کتابخانه موردنیاز
- Procfile: دستور اجرا برای سرویس‌هایی که از آن پشتیبانی می‌کنند

راه‌اندازی:
1. یک ربات از BotFather بسازید و توکن آن را دریافت کنید.
2. در تنظیمات هاست، متغیر محیطی BOT_TOKEN را بسازید و توکن را در مقدار آن قرار دهید.
3. دستور نصب وابستگی‌ها: pip install -r requirements.txt
4. دستور اجرا: python bot.py

این ربات فقط اطلاعات عمومی همان کاربری را نشان می‌دهد که به ربات پیام داده است.
توکن ربات را در GitHub یا داخل فایل bot.py قرار ندهید.
